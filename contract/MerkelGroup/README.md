# MerkelGroup Legacy Entry

The `MerkelGroup` path is retained only for historical link compatibility.

The current extensible community architecture lives in the dedicated [`BaseCommunity` directory](../BaseCommunity/README.md). It uses a shared abstract base, kind-specific leaf contracts and BeaconProxy upgrade domains.

The earlier EIP-1167 `Community + Room` snapshots have moved to [`legacy/v1-clone-room/`](./legacy/v1-clone-room/). They are historical references and must not be used as the source of truth for a new integration.
